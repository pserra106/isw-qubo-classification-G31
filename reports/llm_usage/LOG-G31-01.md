## Part 1: Data Preprocessing (`preprocessing.py`)

### 1. Context and Objective
The goal was to implement the first phase of the pipeline: data preprocessing. The script needed to read a raw CSV dataset, isolate the target column, remove features with a high percentage of missing values based on a user-defined threshold, apply Z-score normalization, and export the processed data along with a JSON report containing execution metrics.

### 2. Prompts and Interactions

**Prompt 1 (Initial Setup):**
> "I need to write a Python script for a machine learning pipeline. The script must read a CSV file, separate a specific 'target' column, and then drop all other columns that have a percentage of missing values (NaN) strictly greater than a threshold passed as an argument. Finally, it must apply Z-score normalization to the remaining features. Can you provide the pandas and scikit-learn logic for this?"

**LLM Response Summary:**
The LLM provided a standard approach using `pandas` to calculate the missing value percentages (`df.isnull().mean()`) and `StandardScaler` from `sklearn.preprocessing` for the Z-score normalization. It also suggested dropping the target column before scaling to avoid normalizing the target variable.

**Prompt 2 (Metrics and JSON Output):**
> "Now I need to track the execution time of the reading process and the normalization process separately. I also need to save the list of dropped features and the final number of features. All this data must be saved into a JSON file, while the normalized dataframe is saved to a new CSV."

**LLM Response Summary:**
The LLM provided the code to use the `time` module to track `t_read` and `t_process`. It demonstrated how to structure a Python dictionary with the required metrics and export it using `json.dump()`.

### 3. Code Integration and Refinement
The generated logic was accurate, but it lacked the specific Command Line Interface (CLI) required by our project architecture. I manually integrated the LLM's core logic into a function and wrapped it with `argparse` to handle parameters.

## Part 3: QUBO Feature Selection (`feature_selection.py`)

### 1. Context and Objective
The objective was to implement the core algorithmic requirement of the project: feature selection using a Quadratic Unconstrained Binary Optimization (QUBO) approach. The goal was to maximize feature relevance (Spearman correlation with the target) and minimize feature redundancy (Spearman correlation between features) using D-Wave's Simulated Annealing.

### 2. Prompts and Interactions

**Prompt 1 (Mathematical Formulation):**
> "I need to formulate a feature selection problem as a QUBO model. I have an array of correlations with the target (relevance) and a matrix of correlations between features (redundancy). How do I build the Q dictionary required by D-Wave's `dimod` or `neal`?"

**LLM Response Summary:**
The LLM explained how to map the problem into linear and quadratic terms. It provided the logic to assign `-(alpha) * relevance` to the diagonal elements `(i, i)` of the Q dictionary, and `(1 - alpha) * redundancy` to the upper-triangle off-diagonal elements `(i, j)`.

**Prompt 2 (Optimization Loop and D-Wave Neal):**
> "I need to iterate through different values of alpha using a grid search (e.g., using `np.linspace`). For each alpha, I will run `neal.SimulatedAnnealingSampler()`. How do I extract the selected features and ensure the dataset split is safe?"

**LLM Response Summary:**
The LLM provided the syntax to run the solver `sampler.sample_qubo(Q)` and extract the lowest energy sample. It also strongly recommended using `train_test_split` from `scikit-learn` with a fixed seed rather than doing a hard index cut, to ensure a balanced and randomized split of the reduced dataset.

### 3. Code Integration and Refinement
I integrated the QUBO formulation and the optimization loop. I refined the grid search to stop when the target number of features (within a specified allowance) was reached. I also added defensive coding to force the selection of at least one feature in case of extreme alpha penalization.
